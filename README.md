# Brand refresh media, October 2026

Public media for scheduled Tayari by KMG and Uza by KMG social posts (Metricool). Not application code.

Every file here is a copy of a scheduled post's artwork with the old product logos replaced by the new KMG family lockups (Uza, KMG Connect, Vital Flex, Enda, each with the BY KMG Vital Links pill).

| Folder | Contents |
|---|---|
| `squares/` | 1080x1080 JPEG squares. JPEG keeps TikTok photo posts within its JPEG or WebP, 1080p limit. |
| `videos/` | Reels (9:16) and walkthroughs (16:9) re-encoded with the new lockups, H.264 and AAC. |

File names keep the Metricool file number of the original asset (`sq-<number>.jpg`, `v-<number>.mp4`) so each one can be traced back to the post it replaced.
